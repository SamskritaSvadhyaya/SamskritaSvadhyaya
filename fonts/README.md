# Fonts

`bonum-*.woff2` — **TeX Gyre Bonum** (a free recreation of Bookman by GUST, the Polish TeX
Users Group), used for the site's English reading text so readers without Bookman Old Style
installed still see a Bookman face. Downloaded from CTAN
(https://ctan.org/pkg/tex-gyre — `fonts/tex-gyre/opentype/texgyrebonum-*.otf`), converted to
WOFF2 and subset to Latin (incl. IAST diacritics) with fontTools.
